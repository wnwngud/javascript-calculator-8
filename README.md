# javascript-calculator-precours

##  구현 기능 목록

### 1. 사용자 입력 기능
- 사용자에게 문자열을 입력받는다.
- <code>Console.readLineAsync()</code>를 통해 입력받는다.
 - <code>Console.print()</code>를 통해 결과를 출력한다

### 2. 기본 구분자로 문자열 분리 기능
- 쉼표(,), 또는 콜론(:)을 기본 구분자로 정의한다.
- 입력받은 문자열 내에 기본 구분자와 양수를 분리한다.
- 기본 구분자를 배열에 넣어 관리한다.
- 함수로 구현하며, 해당 함수는 배열을 반환한다.

### 3. 양수의 합 기능
- 구분자를 제외한, 그 외의 문자만 남은 배열을 정수형으로 바꾼다.
- 합을 구하여 반환한다.

### 4. 커스텀 구분자로 문자열 분리 기능
- "//"과, "\n" 사이에 위치하는 문자를 커스텀 구분자로 정의한다.
- 입력받은 문자열 내의 커스텀 구분자를 분리하여 구분자 배열에 넣어 관리한다.
- 커스텀 구분자와 기본 구분자로 분리한 배열을 반환한다.

### 5. 예외 처리
- 예외발생 시, 사용자에게 '[ERROR]'로 시작하는 에러 메시지를 출력한다.

  ### 예외사항
  - 커스텀 구분자로 숫자를 사용한 경우
  - 커스텀 구분자의 길이가 2 이상인 경우
  - 음수를 입력한 경우
  - 0으로 시작하는 수를 입력한 경우
  - 구분자의 길이가 2 이상인 경우
  - 그 외 문장 형식의 오류
